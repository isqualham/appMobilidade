# ViaU — Mobilidade Urbana

O ViaU é um projeto de superapp de mobilidade urbana desenvolvido para conectar passageiros e prestadores de serviços em uma única plataforma. A proposta é oferecer uma experiência prática, moderna e intuitiva para solicitações de transporte e entregas, começando pela cidade de Cáceres, Mato Grosso, com possibilidade de expansão para outras regiões do Brasil.

O aplicativo prevê diferentes modalidades de serviço, incluindo transporte por carro, mototáxi, táxi e entregas, com experiências específicas para clientes e prestadores dentro da mesma aplicação.

## Funcionalidades planejadas

- Solicitação de corridas e serviços de mobilidade.
- Modalidades de carro, mototáxi, táxi e entregas.
- Interfaces dedicadas para clientes e prestadores.
- Cadastro de prestadores com envio e análise de documentos.
- Acompanhamento de solicitações e corridas por mapa.
- Histórico de atividades e resumo de ganhos.
- Arquitetura preparada para expansão gradual de funcionalidades.

## Tecnologias

- **React Native** — desenvolvimento da interface mobile.
- **Expo** — ambiente e ferramentas para desenvolvimento do aplicativo.
- **TypeScript** — tipagem estática e organização do código.

## Objetivo

Construir uma plataforma escalável de mobilidade urbana, com identidade visual própria, arquitetura modular e possibilidade de evoluir para um ecossistema de serviços digitais.

**Status:** Em desenvolvimento.

_Este repositório concentra o desenvolvimento da interface mobile. As funcionalidades descritas podem estar em fase de planejamento ou prototipação e não representam necessariamente recursos já operacionais._
